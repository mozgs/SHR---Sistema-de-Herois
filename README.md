# SHR — Super Hero RPG

Protótipo inicial de uma central para RPG de heróis.

## Como visualizar
Abra `index.html` no navegador.

## Como publicar com GitHub Pages
1. Crie um repositório público no GitHub chamado `shr`.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde o GitHub publicar o endereço do site.

## Observações
- Os personagens são salvos no `localStorage` do navegador/dispositivo.
- Este protótipo ainda não possui autenticação, banco de dados ou sincronização entre usuários.
- Não coloque senhas ou dados privados neste protótipo.
